## About description

Permission-aware document retrieval with a Streamlit explorer, PostgreSQL row-level security, and tenant audit chains. Independent Python project using synthetic hospital records.

This project uses the visual identity of [CGC Labs](https://cgclabs.org/), a data engineering consulting firm. It is an independent demonstration using synthetic records.

## Publication status

Source code and project documentation are available in the public repository above. Community Cloud deployment remains pending; no hosted app URL has been recorded.

[Deployment instructions](streamlit-deployment.md) and a [portfolio integration snippet](portfolio-integration.md) are included. The app requires no database connection or model API key. Its profile selectors and session audit trail are public demonstrations; the PostgreSQL backend remains separate.
